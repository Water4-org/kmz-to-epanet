⚠ Post-Conversion Checklist

  • Verify pipe diameters — colors auto-mapped to NUMA scheme; name-based fallback applied where available
  • Check node elevations — load SRTM tiles above for automatic enrichment, or set manually in EPANET
  • Satellite backdrop — keep network_backdrop.bmp in the same folder as the .inp; in EPANET use View ▸ Backdrop ▸ Show if it doesn't appear
  • Add reservoirs, pumps, and valves as required — water towers from your KML are auto-detected as Tanks
  • Set node demands based on actual consumption data
  • Check network connectivity — isolated nodes cause solver errors
  • Run a trial simulation and review EPANET warnings
